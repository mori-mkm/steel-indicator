# IPIA Brasil — Índice de Paridade de Importação do Aço

Motor de cálculo do IPIA (bobina laminada a quente) e, no futuro,
vergalhão e cesta multi-produto. Metodologia: janela de padronização
congelada, dado público (Comex Stat, BCB, CVM ITR), sem licença de
agência de preços.

## Uso
    python src/indices_setoriais.py --selftest
    python src/indices_setoriais.py --check-sources
